# AnimatedBottomBar vendored source

This module contains the library source from https://github.com/Droppers/AnimatedBottomBar
at commit 7fcb9afa795706489113789e68ad8ed5b8b1016f.

The source is distributed under the MIT License; see LICENSE in this directory.
It is vendored because Kujaku needs the upstream vertical-bar attributes that are absent
from the published Maven Central artifact, and the JitPack artifacts could not be resolved
reliably by the project's CI.
